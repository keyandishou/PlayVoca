# PlayVoca Privacy Policy Site

This repository contains the GitHub Pages privacy policy site for PlayVoca.

## Enable GitHub Pages

In the GitHub repository, go to:

**Settings → Pages → Deploy from a branch → main → /root**

Save the Pages settings and wait for the deployment to finish.

## Privacy Policy URL

The published privacy policy URL will use this format:

`https://keyandishou.github.io/<repository-name>/privacy.html`
